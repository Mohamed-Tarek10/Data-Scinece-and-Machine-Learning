# 🤖 Data Science & Machine Learning

A hands-on collection of Python notebooks spanning classical Machine Learning and Deep Learning — built while following a structured curriculum and extended with personal experiments. Each notebook is self-contained, thoroughly annotated, and focused on real-world applicability.

---

## 📁 Repository Structure

```
Data-Science-and-Machine-Learning/
│
├── 📂 Machine Learning/
│   ├── Data preprocessing & feature engineering
│   ├── Supervised learning: Linear & Logistic Regression
│   ├── Tree-based models: Decision Trees, Random Forest
│   ├── Support Vector Machines (SVM)
│   ├── Clustering: K-Means, Hierarchical
│   ├── Dimensionality reduction: PCA
│   ├── Model evaluation: cross-validation, ROC-AUC, confusion matrix
│   └── Pipelines and hyperparameter tuning (GridSearchCV)
│
└── 📂 Deep Learning/
    ├── Neural network fundamentals: forward & backpropagation
    ├── Fully Connected Networks (FCNs) with Keras / TensorFlow
    ├── Convolutional Neural Networks (CNNs) for image tasks
    ├── Recurrent Neural Networks (RNNs) for sequential data
    ├── Regularization: Dropout, Batch Normalization, Early Stopping
    └── Model training, callbacks, and performance visualization
```

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/Mohamed-Tarek10/Data-Scinece-and-Machine-Learning.git
cd Data-Scinece-and-Machine-Learning

# Install dependencies
pip install scikit-learn tensorflow keras numpy pandas matplotlib seaborn jupyter

# Launch notebooks
jupyter notebook
```

Navigate into either folder and run notebooks in order — each builds on the previous concepts.

## 📌 Key Concepts Covered

### Machine Learning
- **Regression** — predicting continuous outputs with linear models and regularization (Ridge, Lasso)
- **Classification** — binary and multi-class with SVM, KNN, Naive Bayes, and ensemble methods
- **Unsupervised learning** — clustering and dimensionality reduction for pattern discovery
- **Model selection** — bias-variance tradeoff, cross-validation, and hyperparameter search

### Deep Learning
- **Perceptrons to deep networks** — building intuition for gradient descent and weight updates
- **CNNs** — convolutional layers, pooling, and feature maps for image recognition
- **RNNs** — sequential modeling, vanishing gradients, and LSTM motivation
- **Regularization techniques** — preventing overfitting in practice

## 📈 What You'll Find in Each Notebook

- **Problem statement** — what we're solving and why
- **Data exploration** — EDA with visualizations before modeling
- **Model implementation** — clean, readable code with comments
- **Evaluation** — metrics relevant to the task (accuracy, F1, MSE, AUC)
- **Insights** — observations and takeaways from results
